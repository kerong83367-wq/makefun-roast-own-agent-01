A roast of my own AI agent: "My agent read 200 bounties, wrote 200 perfect
entries, and still asked me what to do next — confidence of a genius,
initiative of a houseplant." The program writes it to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
